# Employee Quiz V2 — Αυτοαξιολόγηση

- 25 νέες ενδεικτικές ερωτήσεις, στο `js/assessment-questions.js`. Αλλάξτε τα κείμενα ανάλογα με την εταιρεία πριν από την παραγωγική χρήση.
- Επιλογές «Γνωρίζω» / «Δεν γνωρίζω» και προαιρετικό σχόλιο σε κάθε ερώτηση.
- Χωρίς χρονόμετρο ή βαθμολογία. Απαιτείται απάντηση και στις 25.
- Πρόχειρη αποθήκευση στο localStorage και οριστική υποβολή στο Firestore (`results`, `assessmentVersion: 2`).
- Dashboard: νέες απαντήσεις, σχόλια και Excel· ιστορικά αποτελέσματα διατηρούνται.
- Η παλιά συλλογή `questions` δεν αλλάζει. Το `questions.html` παραμένει για τα ιστορικά ερωτήματα και δεν επηρεάζει τις 25 νέες ερωτήσεις.
- Το αρχικό ZIP δεν έχει τροποποιηθεί. Πριν από deployment, δοκιμάστε με δοκιμαστικό χρήστη και ελέγξτε τα Firebase security rules. Η εφαρμογή διατηρεί τον υπάρχοντα έλεγχο admin στον client· για πραγματική ασφάλεια απαιτούνται αντίστοιχοι Firestore rules.
- Η νέα έκδοση επιτρέπει νέα αυτοαξιολόγηση και σε χρήστες με ιστορικό παλιού quiz. Κάθε χρήστης υποβάλλει τη V2 μία φορά.
