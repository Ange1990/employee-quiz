# Employee Quiz V3 — Γνωστικά αντικείμενα

Οι επικεφαλίδες προέρχονται από την πρώτη γραμμή του Excel.

- **ERP**: 64 γνωστικά αντικείμενα
- **ΜΙΣΘΟΔΟΣΙΑ ΛΟΓΙΣΤΙΚΗ**: 3 γνωστικά αντικείμενα
- **ΞΕΝΟΔΟΧΕΙΟ**: 4 γνωστικά αντικείμενα

**Σύνολο: 71 αντικείμενα.** Κάθε αντικείμενο εμφανίζεται με «Γνωρίζω», «Δεν γνωρίζω» και προαιρετικά σχόλια.

Η εφαρμογή δείχνει την επικεφαλίδα ενότητας σε κάθε ερώτηση και διατηρεί τη σειρά ERP → ΜΙΣΘΟΔΟΣΙΑ ΛΟΓΙΣΤΙΚΗ → ΞΕΝΟΔΟΧΕΙΟ. Οι απαντήσεις αποθηκεύονται ως assessmentVersion 3 με ξεχωριστό document id, χωρίς να αντικαθιστούν προηγούμενα αποτελέσματα. Το Dashboard εμφανίζει την ενότητα σε κάθε γραμμή και στην εξαγωγή Excel.

Δεν έχει γίνει καμία τροποποίηση στο GitHub ή στο Firebase. Ελέγξτε τη λειτουργία με δοκιμαστικό χρήστη και τους κανόνες πρόσβασης Firestore πριν από τη δημοσίευση.
